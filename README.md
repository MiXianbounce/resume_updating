# 陈茗瑄 产品项目作品集

用于 GitHub Pages 的静态作品集，展示知识管理、AI 工作流、用户研究、内容产品、路线体验与界面设计项目。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，建议名称为 `portfolio`。
2. 将本文件夹全部内容上传到仓库根目录。
3. 打开仓库 `Settings` → `Pages`，在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择 `main` 分支和 `/ (root)`，保存。
5. 页面地址会显示在 GitHub Pages 设置页中，通常形式为 `https://你的GitHub用户名.github.io/portfolio/`。

简历中可放：`作品集：https://你的GitHub用户名.github.io/portfolio/`。

本目录只包含已脱敏的网页、图片和样式文件，不包含未发表论文原始数据、完整 Notebook 或 API Key。项目说明按个人实际职责撰写，团队项目会区分个人负责内容与协作成果。
